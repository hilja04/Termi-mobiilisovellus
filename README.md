# Termi-mobiilisovellus

Termi on sovellus, jonka avulla voi opiskella kielisanastoa ja termejä. Sovelluksessa voi luoda ja hallinnoida korttipakkoja ja kortteja sekä tarkastella omia testituloksia. Kortteja voi opiskella kolmella eri tavalla: flashcard-pelillä, monivalinnalla ja kirjallisella testillä
