# Termi-mobiilisovellus

Termi on mobiilisovellus, jonka avulla voi opiskella kielisanastoa ja termejä. Sovelluksessa voi luoda ja hallinnoida korttipakkoja ja kortteja sekä tarkastella omia testituloksia. Kortteja voi opiskella erilaisilla opiskelutavoilla, joita sovellus tarjoaa kolme. Sovellus toteutettiin osana Haaga-Helian opinnäytetyötä

## Keskeiset teknologiat

- JavaScript
- React
- React Native
- Expo
- SQLite

## Käytettyjä kirjastoja

- React Navigation
- React Native Paper
- React Native Popup Menu
- Expo Linear Gradient

## Keskeiset ominaisuudet

- Korttipakkojen luonti, muokkaus ja poistaminen
- Kaksipuolisten korttien luonti ja poistaminen
- Korttien kääntäminen 
- Kolme eri harjoittelutapaa:
  - Flashcard-peli
  - Monivalinta testi
  - Kirjallinen testi
- Testitulosten tallennus ja tarkastelu
